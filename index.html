Core Law of Agentic Workflows

"The agent that writes the fix must never be the agent that approves it."

When an LLM evaluates its own code, it suffers from confirmation bias and will readily approve hardcoded, fake, or fragile patches. The Maker-Checker pattern isolates the implementer from an independent read-only reviewer with separate evaluation criteria.
